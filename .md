## ✨ Overview

Fern is a multi-component project built around a Discord-integrated client experience. It includes a web interface, backend services, and a Discord bot for managing community workflows.

### Features

- 🌐 **Web Interface** — A dedicated interface built with the Fern UI.
- 🔗 **Discord Integration** — A companion bot for server-side functionality.
- 🛠️ **Backend Services** — Supporting application services and API functionality.
- 🎫 **Ticket System** — Discord-based ticket and support workflows.
- 🔑 **Licensing Service** — A dedicated service for license-related functionality.
- 🧩 **Modular Architecture** — Separate components that can be developed and maintained independently.
- 🆓 **Open Source** — Inspect, modify, and contribute to the project.

> **Note:** Fern's exact peer-to-peer networking and encryption capabilities depend on the current implementation. Review the source code and documentation before relying on any privacy or security guarantees.

## 📋 Requirements

Before installing Fern, make sure you have the following installed:

- [Node.js and npm](https://nodejs.org/) — Required for the web interface.
- [Python 3](https://www.python.org/downloads/) — Required for the Python services and bot.
- [Git](https://git-scm.com/downloads) — Recommended for cloning and updating the repository.

Verify your installations:

```bash
node --version
npm --version
py --version
```

If `py` is unavailable, try `python --version`.

## 🚀 Installation

### 1. Configure the Discord bot

Open `fern-bot/.env` and enter your Discord configuration:

- `BOT_TOKEN` — Your Discord bot token.
- `GUILD_ID` — Your Discord server ID.
- `ADMIN_ROLE_ID` — The ID of your administrator role.
- `REVIEW_CHANNEL_ID` — The ID of your review channel.
- `TICKET_CATEGORY_ID` — The ID of your ticket category.

**Important:** Use the existing variable names in your `.env` file. Only update the required values and leave the other settings unchanged.

Keep your bot token private. Never commit `.env` files or other secrets to a public repository.

### 2. Install and build the UI

Open a terminal in the project directory and run:

```bash
cd fern-ui
npm install
npm run build
```

Wait for the build to finish successfully before continuing.

### 3. Install Python dependencies

Return to the project root if necessary, then install the dependencies:

```bash
cd ..
pip install -r requirements.txt
```

Run this command from the directory containing `requirements.txt`. If your project uses a virtual environment, activate it first.

### 4. Start the application services

From the appropriate project directory, start each service using its corresponding batch file:

```text
openapp.bat
openui.bat
openlicense.bat
```

Keep the service windows running while using Fern.

### 5. Start the Discord bot

Open another terminal and run:

```bash
cd fern-bot
py main.py
```

The bot should start using the configuration supplied in `fern-bot/.env`.

## 🧰 Troubleshooting

### `ModuleNotFoundError`

If Python reports that a module is missing, install the missing package:

```bash
pip install <module>
```

Replace `<module>` with the actual missing package name. If the module is part of the project's dependencies, try reinstalling them:

```bash
pip install -r requirements.txt
```

### `npm` is not recognized

Install Node.js from [nodejs.org](https://nodejs.org/), then reopen your terminal and check:

```bash
node --version
npm --version
```

### The UI fails to build

Make sure you are in the correct directory:

```bash
cd fern-ui
npm install
npm run build
```

Check the terminal output for the first error if the build fails.

### The Discord bot does not start

- Check that the values in `fern-bot/.env` are correct.
- Confirm that the bot has been invited to your Discord server.
- Verify its permissions and configured channel and role IDs.
- Make sure the required Python dependencies are installed.
- Check the terminal output for the specific error.

### A service closes immediately

Run the relevant `.bat` file from an open Command Prompt so that you can read the error output before the window closes.

## 🔐 Security

- Never publish your Discord bot token, API keys, credentials, or private environment files.
- Do not assume peer-to-peer communication automatically provides end-to-end encryption.
